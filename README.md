# Cellscope

Cellscope 在本地检查太阳能面板的电致发光（EL）照片。导入相机原片或从「照片准备」传入合成结果，按原片像素定位观察范围。工作台保留原片、参数和历次检查。

## 启动

运行 `./start.sh` 后打开 [本地检查台](http://127.0.0.1:19885/)。工作台使用 Docker Compose 与独立命名卷。更改本地服务端口可设置 `CELLSCOPE_PORT`。运行 `./start.sh stop` 停止服务，数据仍留在卷内。

## 使用

1. 在照片库选择「载入练习」，或导入一张 PNG、TIFF 或 JPEG。练习照片为合成面板，提供暗斑、亮点、焊带、裂纹和边沿缺口。
2. 在照片上点击检查框的两个对角点。以用户已知的物理比例填写 mm/px，设置电池片行列数，选择检查项目。点击「保留设置」可在重开照片后继续使用。
3. 「电池片亮度」按检查区的等分网格显示电池片亮度中位数与暗像素占比。「暗区面积」和「亮斑定位」分别按灰度及最小连通块面积过滤并标出原片位置。「焊带位置」在手工圈定的小窗中标出列向暗带。
4. 「画剖线」接受两个原片端点，读出一段可见直线的旁读对比和物理长度。「暂留剖线」可保留多段可疑线迹供分别复查。点击曲线上某点会在原片标出对应位置。
5. 「边沿缺口」沿检查区上边量测内缩。「行列均匀度」给出原片灰度趋势及极端行列。「灰度分布」显示全区域直方图、近黑数和分位数。
6. 「保存检查」封存这次的参数、读数与标记。重开检查记录后可下载 CSV 和叠加标记 PNG。下载图保留原片尺寸。未保存的实时读数可用重算更新。
7. 「照片准备」支持多帧导入、配准、质检、合成、色彩校正、版本记录与导出，并能将生成结果送回检查台。

单张照片最大 22 MB，至少 32 × 32 像素，最多 1400 万像素。单通道 16 位照片按 16 位取样，显示用浏览器预览，叠加标记 PNG 为 RGB。RGB 摄影转亮度，均匀度和灰度阈值为原片量程指标。用于读片复核的等分网格、直线剖线、列向焊带、阈值区域与上边测量需要用户先确认正确的取景与标定。区域列表显示面积最大的 80 个连通块，总面积计入所有达到最小面积的连通块。照片准备页支持的多帧工作量另受其工程参数限制。

正常容器使用锁定的 Python 3.12 依赖，正式环境也支持锁定的 Python 3.11 依赖。可运行 `python3 scripts/count_backend.py --project-root . --source-root cellscope --source-root image_lab --output backend-count.json` 复算 Python 后端有效行。
